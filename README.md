Using Pynvml library i created a simple gpu monitor system that shows the following aspects regarding a gpu :

1-GPU Temprature

2- GPU Power Consumption 

3- GPU Utilization 

4- The Windows that the user uses at the moment

Also with the ability to log each of the mentioned into a external .csv file.
